# Matt Hansel: механики для Tomorrow
Дата фиксации: 6 ноября 2026. Автор предложений: Codex, по обсуждению с Елисеем. Елисей явно попросил сохранить примеры: они ему нравятся. Это одобрение направления исследования, не согласование всех механик к реализации.

## Что переносим
Не живопись, персонажей, палитру или мрачность Hansel. Переносим отношения: знакомая вещь содержит невозможное; странность ведёт себя буднично; внимательность меняет понимание увиденного. Это интерпретация для проекта, не утверждение о намерениях художника.

| Механика | Возможное взаимодействие | Ощущение |
|---|---|---|
| Знакомое содержит несоразмерно большое | Маленькая сноска раскрывается в пространную композицию. При возвращении всё снова помещается в тот же крошечный знак. | «Как это там помещалось?» |
| Странное оказывается участником | Уже существующая нора меняет положение и становится проходом для текста. После события спокойно возвращается на место. | «У этого мира есть собственная жизнь» |
| Невозможное ведёт себя буднично | Абзац огибает пустое место так, будто там стоит предмет. Позже через это место что-то проходит, раскрывая его функцию. | «Значит, эта пустота всё время была чем-то» |
| Изображение обнаруживает материальность | Линия подчёркивания приоткрывается, текст проходит за неё и возникает с другой стороны. | «Я неправильно понимал, на что смотрю» |
| Наблюдатель оказывается замечен | После твоего действия появляется чужая каретка и вносит осмысленную правку — оммаж четвёртой стене. | «Здесь кто-то отвечает мне» |
| Возвращение меняет знакомое | При обратном скролле два элемента уже образуют связь, которую ты помог создать; текст остаётся прежним. | «Моё присутствие что-то изменило» |

## Интонация
Невозможное происходит уверенно и без объявления фокуса. Точная механика движения делает невозможное убедительным. Изобилие можно разложить по времени и действиям, сохранив спокойный экран. Не каждой находке нужна информационная польза: возможны юмор, контакт с автором, изменение отношения к пространству.

У Hansel полезна возможность сосуществования с непривычным. Для Tomorrow проверяем притяжение и лёгкое сомнение, без отвращения и демонстративного гротеска.

Jefferson Airplane: иди за тем, что притягивает.
Hansel в нашей интерпретации: встреченное может быть странным, и с ним возможна жизнь.
Tomorrow: попробуй взаимодействовать — мир допускает больше, чем кажется.

## Фильтр для дальнейшего выбора
«Мир обещает больше, чем ты пока умеешь замечать» + «Хочется проверить самому».
Цель обсуждения — найти своих. Дать испытать способ мышления — метод, а не отдельная цель.
Интеллектуальность относительна; сложность — отдельная ось. Богатство открытий не требует постоянной нагрузки на внимание.
